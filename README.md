# Verbalia — release

Questo repository contiene **solo gli artefatti compilati** (immagini Docker esportate, `.tar.gz`)
delle versioni di [Verbalia](https://github.com/m4tt308/Verbalia), pubblicati qui per permettere
l'aggiornamento automatico delle installazioni server (vedi `packaging/server/updater` nel
repository principale, privato).

Non contiene codice sorgente. Il repository di Verbalia resta privato.
